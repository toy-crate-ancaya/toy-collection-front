## 📱 Sobre o Projeto

O Toy Collection é uma aplicação móvel que permite aos usuários gerenciar sua coleção de brinquedos de forma intuitiva e organizada. Desenvolvida com tecnologias modernas e focada em uma excelente experiência do usuário.

## ✨ Funcionalidades

- 📸 Cadastro de brinquedos com fotos
- 📊 Organização por categorias
- 🏷️ Sistema de tags e etiquetas
- 🔍 Busca avançada
- 📱 Interface responsiva
- 💾 Backup automático
- 🌐 Sincronização em nuvem
- 📊 Estatísticas da coleção
- 🎨 Temas personalizáveis
- 🔔 Sistema de notificações

## 🚀 Tecnologias Utilizadas

- [React Native](https://reactnative.dev/) - Framework para desenvolvimento mobile
- [Expo](https://expo.dev/) - Plataforma para desenvolvimento React Native
- [Axios](https://axios-http.com/) - Cliente HTTP para requisições à API
- [Expo Vector Icons](https://docs.expo.dev/guides/icons/) - Biblioteca de ícones
- [Expo Image Picker](https://docs.expo.dev/versions/latest/sdk/imagepicker/) - Seleção de imagens do dispositivo

## 🏗️ Estrutura do Projeto

```
src/
├── assets/      # 🖼️ Recursos estáticos (imagens, fontes, etc)

```

## ⚙️ Como Executar

1. Clone o repositório:
```bash
git clone [URL_DO_REPOSITÓRIO]
```

2. Instale as dependências:
```bash
npm install
```

3. Configure as variáveis de ambiente:
```bash
cp .env.example .env
```

4. Inicie o projeto:
```bash
npm start
```

5. Use o aplicativo Expo Go no seu dispositivo móvel para escanear o QR Code ou execute em um emulador.

## 📱 Comandos Disponíveis

- `npm start` - 🚀 Inicia o servidor de desenvolvimento Expo
- `npm run android` - 🤖 Inicia a aplicação no Android
- `npm run ios` - 🍎 Inicia a aplicação no iOS
- `npm run web` - 🌐 Inicia a aplicação na web
- `npm run test` - 🧪 Executa os testes
- `npm run lint` - 🔍 Verifica problemas no código
- `npm run build` - 📦 Gera o build de produção

## 🔧 Requisitos do Sistema

- 📱 Node.js 14 ou superior
- 📦 npm ou yarn
- 🚀 Expo CLI
- 🤖 Android Studio (para emulador Android)
- 🍎 Xcode (para emulador iOS - apenas macOS)
